# Plexcord Backend

Plexcord Backend is the API for the Plexcord client mod, providing cloud settings synchronization and other functionalities.

## Cloning the Repository

First, clone the source code to a convenient location:
```sh
git clone https://github.com/Plexcord/Backend
```

## Setting up the Configuration

Copy the example configuration file `.env.example` to `.env`. Open the `.env` file with your preferred text editor and fill in the configuration values. All variables are documented in the file.

## Installing Dependencies

Navigate to the Backend directory:
```sh
cd Backend
```

Install dependencies using one of the following commands:
```sh
npm install
```
or
```sh
yarn install
```

## Running the Application

To run the application in development mode:
```sh
npm run dev
```
or
```sh
yarn dev
```

To run the application in production mode:
```sh
npm start
```
or
```sh
yarn start
```
